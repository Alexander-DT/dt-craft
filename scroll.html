Component lab · 07  /  Scroll

Every section, its own set-piece.

Six scroll treatments, one per section. All six share a single rig — a tall section holding a pinned stage that writes one scrubbed value across itself — and everything else is CSS reading that value. Which means all six run backwards as cleanly as forwards, and a seventh is a block of CSS rather than another script.

Set-piece 01 · Gradient text

Read as you scroll.

The sentence is set twice: a dim copy that never moves, and a lit copy uncovered from the top a line at a time. The gradient inside the lit copy travels as well, so the brightest point stays near the line being read rather than sitting still.

  • background-clip: text
  • clip-path wipe
  • Travelling gradient
  • Real text underneath

Set-piece 02 · Split screen

The word comes apart.

One word, drawn twice at exactly the same place, with each half of the screen clipping its own half of it. As the two panels part the word splits along the midline and what was behind it arrives — no duplicate assets, no measuring.

Set-piece 03 · Word cascade

One word at a time.

Each word carries its own offset into the same scrubbed value and mixes from the dim ink to the bright accent as the scroll passes it. The paragraph is still a paragraph in the accessibility tree — only the visible layer is split.

  • Per-word offset
  • color-mix in oklab
  • Real sentence for readers
  • No opacity stacking

Set-piece 04 · Horizontal pan

Down the page, across the work.

Vertical scroll driving horizontal travel. The overshoot is 100vw - 100% of the track itself, so the pan always ends exactly on the last card whatever is in it — nothing measured, nothing to go stale on resize.

  • Pure CSS distance
  • No measurement
  • Ends flush
  • Scrollable under reduced motion

Set-piece 05 · Cinematic counter

Count in, then hand over.

A number counting to a hundred while the frame behind it un-dims and settles out of an over-scale, then the number stands down and the lines take over — each on its own offset. Title sequence pacing, entirely on the scrollbar.

  • Counter tied to scrub
  • Over-scale settle
  • Staggered line masks
  • Hands off at 58%

Set-piece 06 · Depth flight

Through, not past.

Three planes scaling at very different rates, each fading as it passes the camera. Scale alone reads as distance when the rates are far enough apart — no perspective, no 3D context, nothing that would take the page out of the compositor.

  • Rates 0.5 / 1.6 / 4.2
  • Staggered fade-out
  • Transform + opacity only
  • Copy lands last

One rig, six treatments

Attach one per section.

Every set-piece above is a tall section carrying data-pin and a .pin-stage inside it. The module writes one value; the treatment is CSS. Mixing three of these across a five-page site is what makes it feel authored rather than assembled.
